<p align="center">
  Prism Launcher is a custom launcher for Minecraft that allows you to easily manage multiple installations of Minecraft at once.<br />
</p>

> **Note:** This repository is an unofficial fork of [Prism Launcher](https://github.com/PrismLauncher/PrismLauncher) and is not endorsed by or affiliated with the Prism Launcher project.

## Changes in this fork

- Based on the latest **develop** branch changes, not the stable release.
- Added compiler optimization flags to the build configuration.
- Updated Qt to **6.11.2** on Linux and macOS.
- Updated Qt to **6.10.3** on Windows.
- Trimmed this README down to the essentials.

## Installation

This fork is built from develop, so there are no stable releases. Download the latest build as an artifact from the [GitHub Actions](https://github.com/PrismLauncher/PrismLauncher/actions) tab.
